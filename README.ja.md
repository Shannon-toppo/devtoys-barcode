# Shannon.DevToys.Barcode

英語版: [README.md](README.md)

## 概要

Shannon.DevToys.Barcodeは、DevToys 2.0に「バーコードエンコーダー / デコーダー」ツールを追加する拡張機能です。テキストからバーコードを生成し、画像からバーコードを読み取ります。画面のレイアウトは、DevToysの標準機能であるQRコードツールと同じです。

## 機能

- テキストからバーコードを生成し、PNG形式またはSVG形式で保存できます。SVG形式で保存できるのは、生成したバーコードだけです。
- 画像からバーコードを読み取ります。1つの画像に複数のバーコードがあれば、すべてを検出して種類とともに一覧に表示します。最初の結果がテキスト欄に入ります。
- 回転した画像、傾いたバーコード、白黒反転したバーコード、低コントラストの画像、照明のむら、ノイズや圧縮のある画像にも、一定の範囲で対応します。詳しくは「既知の制限」を参照してください。
- EANとUPCでは、チェックディジットを省略すると自動で計算し、入力された場合は検証します。
- 入力が選択したバーコードの種類に合わない場合、その種類のルールを示すメッセージを表示します。
- 画像は、ファイル選択、ドラッグ＆ドロップ、貼り付けで読み込めます。DevToysのスマート検出（Smart Detection）と連携し、画像とテキストの両方に対応します。
- macOSでは、iPhoneの写真などのHEIC画像とHEIF画像も読み取れます。macOSに標準で入っている`sips`ツールでPNGに変換してから読み取ります。詳しくは「既知の制限」を参照してください。
- 選択したバーコードの種類は記憶されます。画像から検出された種類はドロップダウンで選択されますが、記憶はされません。
- Data Matrix、PDF417、AztecではASCII以外の文字（日本語など）も使えます。文字はUTF-8でエンコードされます。
- 表示言語は英語と日本語です。

## 対応する形式

| 形式 | 生成 | 読み取り |
|---|---|---|
| Code 128（既定） | ○ | ○ |
| EAN-13 | ○ | ○ |
| EAN-8 | ○ | ○ |
| UPC-A | ○ | ○ |
| UPC-E | ○ | ○ |
| Code 39 | ○ | ○ |
| Code 93 | ○ | ○ |
| ITF | ○ | ○ |
| Codabar | ○ | ○ |
| Data Matrix | ○ | ○ |
| PDF417 | ○ | ○ |
| Aztec | ○ | ○ |
| QR Code | － | ○ |

読み取りでは、上記に加えて、ZXing.Netが読み取れるその他の形式（例：GS1 DataBar）も扱えます。QRコードは、DevToysに標準のQRコードツールがあるため、生成の対象にしていません。

## インストール

動作環境はDevToys 2.0です。開発時にはDevToys 2.0.9とmacOSを使用しました。WindowsとLinuxでは動作を確認していません。

1. パッケージの`.nupkg`ファイルを[NuGet](https://www.nuget.org/packages/Shannon.DevToys.Barcode)または[リリースページ](https://github.com/Shannon-toppo/devtoys-barcode/releases)からダウンロードします。
2. DevToysで拡張機能の管理（Manage extensions）を開き、インストール（Install）を選んで`.nupkg`ファイルを指定し、DevToysを再起動します。

インストール後、拡張機能の一覧には「Barcode Encoder / Decoder」と表示されます。この手順はmacOSのDevToys 2.0.9で確認しています。

## 使い方

### バーコードを生成する

1. 「バーコードの種類」のドロップダウンで種類を選びます。
2. テキストを入力します。入力したテキストからバーコードが生成されます。
3. PNG形式またはSVG形式で保存します。生成された画像には、バーの下に読める文字は含まれません。

EANとUPCの種類では、チェックディジットを省略すると計算され、入力すると検証されます。入力したテキストは書き換えられず、エンコードされた値が表示されます。

入力が選んだ種類に合わない場合は、その種類のルールを示すメッセージが表示されます。

### バーコードを読み取る

画像をファイル選択で開くか、ツールにドラッグ＆ドロップするか、貼り付けます。検出されたバーコードは、種類とテキストとともに一覧に表示されます。最初のバーコードのテキストがテキスト欄に入ります。

## コマンドライン

この拡張機能は、DevToysのコマンドラインアプリ（DevToys CLI）に`barcode`コマンドも追加します。処理はアプリのツールと共通で、単体テストで確認しています。ただし、DevToys CLIそのものの上では、まだ動作を確認していません。

バーコードを生成します。出力ファイルの拡張子で形式が決まります。`.svg`、`.png`、`.jpg`、`.bmp`、`.gif`、`.webp`のほか、DevToysが対応する画像形式を使えます。

```
DevToys.CLI barcode --input "Hello-123" --outputfile hello.svg
DevToys.CLI barcode -i 400638133393 -t ean13 -o ean13.png
DevToys.CLI barcode -i labels.txt -t datamatrix -o labels.png
```

`--type`（`-t`）には、`code128`（既定）、`ean13`、`ean8`、`upca`、`upce`、`code39`、`code93`、`itf`、`codabar`、`datamatrix`、`pdf417`、`aztec`のいずれかを指定します。テキストをエンコードできない場合は、理由とその種類のルールをエラー出力に書き出し、終了コード-1で終わります。

画像のバーコードを読み取ります。各バーコードのテキストを、上から下、左から右の順に1行ずつ出力します。

```
DevToys.CLI barcode --input photo.png
DevToys.CLI barcode -i photo.heic --showtype
DevToys.CLI barcode -i photo.png -o result.txt
```

`--showtype`を付けると、各行はバーコードの種類、タブ、テキストの順になります。画像に複数のバーコードがある場合と`--showtype`を付けた場合は、テキスト内の改行を`\n`として出力します。バーコードが見つからない場合は、メッセージをエラー出力に書き出し、終了コード-1で終わります。

`--input`に渡したテキストが、存在しない画像ファイルのパスのように見える場合（例：`photo.png`）は、ファイルが見つからないというエラーになります。そのようなテキストをエンコードするには、テキストファイルに書いて、そのファイルを渡してください。

## 既知の制限

以下は合成画像だけで測定した結果です。写真では検証していません。

- HEIC画像とHEIF画像を読み取れるのはmacOSだけです。macOSの`sips`ツール（`/usr/bin/sips`）で変換しており、追加のインストールは要りません。WindowsとLinuxでは対応しておらず、ファイル選択にも表示されません。変換に失敗した場合や30秒以上かかった場合は、「ファイルを読み込めません」のメッセージが表示されます。
- 強いぼけは読み取れません。密度の高い1次元バーコードは、ガウシアンぼかしの標準偏差（sigma）が約2px以上の場合に読み取れません。
- バーの幅が約2px未満だと、正しく読み取れないことがあります。
- 非常に暗く照明が一様でない場合、強いノイズ、強い透視変形では、一部の種類で読み取りに失敗します。
- 背景が込み入っていると、Data MatrixとAztecを見落とすことがあります。
- Data MatrixとAztecは、周囲の余白（約4モジュール分）より近くにほかの絵柄がある場合や、破損したバーコードに接している場合に、見落とすことがあります。
- 同じバーコードが1つの画像に2つあっても、1件だけ報告されます。
- GS1のアプリケーション識別子は解析されません。元のテキストがそのまま表示されます。
- バーコードのない画像で誤った結果が出ることがあります。頻度は低く、生成したテスト画像約250枚のうち1枚（ランダムノイズの画像）で発生しました。
- バーコードのない12メガピクセルの画像を読み取るには、4コアのLinuxマシンで約1.4秒かかります。

## ソースからのビルド

```
dotnet build
dotnet test
dotnet pack src/DevToys.Barcode -c Release
```

ライブラリはnet8.0を対象とし、テストはnet10.0を対象とします。

macOSでローカルビルドをDevToysで試す場合は、環境変数`EXTRAPLUGIN`にビルド出力の絶対パスを指定してDevToysを起動します。

```
EXTRAPLUGIN=/absolute/path/to/src/DevToys.Barcode/bin/Debug/net8.0 /Applications/DevToys.app/Contents/MacOS/DevToys
```
